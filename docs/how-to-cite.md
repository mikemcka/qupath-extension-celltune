# How to cite

If you use SP Classify in your work, please cite **both** the software and the CellTune paper it
derives from, plus any method papers for the specific features you used. This page mirrors the
in-app **Extensions ▸ SP Classify ▸ How to Cite…** dialog and the machine-readable
[`CITATION.cff`](https://github.com/mikemcka/qupath-extension-sp-classify/blob/main/CITATION.cff).

## Software

> Mckay, M. *SP Classify: an active-learning cell classifier extension for QuPath.* Zenodo.
> [https://doi.org/10.5281/zenodo.21782421](https://doi.org/10.5281/zenodo.21782421)

The Zenodo DOI above is a *concept* DOI that always resolves to the latest release.

## Always cite
